# Déposer la soumission sur GitHub

Si le professeur a fourni un lien GitHub Classroom, suivre ce lien en premier.
Sinon utiliser le dépôt privé de l'équipe et inviter les coéquipiers et le professeur.

1. Extraire l'archive ZIP sur l'ordinateur.
2. Compléter le numéro du groupe dans README.md et renommer le PDF selon la convention demandée.
3. Exécuter `python main.py`, puis `python test_stock.py`.
4. Ouvrir le dépôt GitHub, puis **Add file > Upload files**.
5. Glisser les fichiers et le dossier docs depuis le dossier StockPilot extrait.
   Déposer les fichiers décompressés, pas uniquement le ZIP.
   Le fichier .gitignore peut être ajouté séparément via **Add file > Create new file**.
6. Dans le message de commit, écrire : `Soumission 1 : proposition, prototype et tests`.
7. Cliquer **Commit changes**.
8. Ouvrir le PDF depuis GitHub et vérifier la présence de main.py et test_stock.py.
9. Vérifier que le professeur a accepté son invitation si le dépôt est privé.
10. Remettre le lien du dépôt selon les consignes du professeur ; vérifier si Léa demande aussi ce lien.

Les changements ultérieurs doivent refléter le travail réel de chaque membre.
Ne pas ajouter de mots de passe ou de données personnelles réelles de clients.
